# Quickstart

This quickstart gets you from app launch to your first saved localization.

## 1. Launch and Login

1. Start the app.
2. Enter M3 URL, username, and password.
3. Click **Login**.

<!-- ### Screenshot Placeholder: Login With Credentials Filled

![Login filled placeholder](../images/screenshots/login-dialog-filled.png) -->

## 2. Search For A Concept

1. In the search panel, ensure mode is **Concept**.
2. Enter or select a concept.
3. Click **Go**.

<!-- ### Screenshot Placeholder: Search Panel After Concept Search

![Search results placeholder](../images/screenshots/search-panel-after-query.png) -->

## 3. Select An Observation

1. Select an imaged moment row.
2. Select an observation row under that moment.
3. Confirm the image loads in the main panel.

<!-- ### Screenshot Placeholder: Entry Browser With Selection

![Entry browser selection placeholder](../images/screenshots/entry-browser-selection.png) -->

## 4. Draw A Bounding Box

1. In the image canvas, click and drag over target region.
2. Release to create a localization.
3. Verify new box appears and is associated with the selected observation.

<!-- ### Screenshot Placeholder: Freshly Drawn Bounding Box

![New bounding box placeholder](../images/screenshots/image-canvas-new-box.png) -->

## 5. Edit Localization Properties

1. Double-click a localization box.
2. Update geometry or part metadata.
3. Save changes.

![Properties dialog placeholder](../images/screenshots/properties-dialog-open.png) -->

## 6. Confirm Persisted State

- Reload the moment selection.
- Confirm localization remains present.
