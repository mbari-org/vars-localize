# Keyboard Shortcuts Reference

## Default Shortcuts

- Focus Search: `Ctrl+F`
- Clear Results: `Ctrl+L`
- Open Settings: `Ctrl+,`
- Delete selected observation(s): `Delete`
- Rename selected observation: `Ctrl+R`

## Notes

- Several shortcuts are configurable from **Settings -> General**.
- Changes are applied after saving settings.
