# Troubleshooting

## Cannot Connect To M3

Symptoms:

- Login fails with connection error.

Checks:

- Verify M3 URL.
- Verify VPN/network connectivity.
- Increase connection timeout in settings.

## Login Fails With Valid URL

Checks:

- Verify username/password.
- Verify account role/permissions.

Checks:

- Check service availability/logs.

## SAM3 Not Available

Checks:

- Install SAM extras.
- Confirm model file path exists.
- Confirm runtime can load model.
