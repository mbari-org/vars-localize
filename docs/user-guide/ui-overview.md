# UI Overview

VARS Localize is organized around a docked workflow:

- Left side: search and entry navigation.
- Right side: image display and localization interaction.
- Bottom status bar: activity, user, role, mode, concept, and result count.

## Main Regions

1. **Menu Bar**
2. **Search Panel (Dock)**
3. **Entry Browser Tables**
4. **Display Panel + Image Canvas**
5. **SAM Candidate Controls**
6. **Status Bar**

## Status Bar Fields

- Activity: Ready or Loading.
- User: current observer.
- Role: observer role.
- Mode: Standard or Admin.
- Concept: active concept filter.
- Results: count of loaded result UUIDs.

## Common Interaction Model

- Select data in entry browser.
- Work on geometry in image canvas.
- Use keyboard shortcuts to speed repetitive operations.
- Rely on status indicators to detect loading and context.
