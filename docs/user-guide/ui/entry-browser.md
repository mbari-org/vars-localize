# Entry Browser

The entry browser provides three synchronized tables:

- Imaged moments
- Observations
- Associations

## Concept Focus Controls

At top of the browser:

- **Annotate Concept** dropdown narrows active concept focus.
- **Clear Concept** resets concept filter.
- **Clear Observation** removes selected observation context.

## Moments Table

Shows each moment with:

- Row number
- Observation count summary
- Localization status (Empty, Unlocalized, Partial, Localized)

## Observations Table

Shows selected moment observations and allows:

- Single or multi-row selection.
- Delete via **Delete** key.
- Rename via **Ctrl+R**.
- Double-click to open detail popup.
