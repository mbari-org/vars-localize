# Image Canvas

The image canvas is where localization geometry is created and edited.

## Primary Actions

- Click-drag to create a new bounding box.
- Click existing box to select.
- Drag handles to resize selected box.
- Double-click box to open properties.

## Properties Dialog

Double-clicking a localization opens a properties editor for:

- Concept display
- Part selection
- X/Y position
- Width/Height
- Delete action
