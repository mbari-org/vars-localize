# Login Dialog

The login dialog appears at startup and gates access to M3-backed operations.

## Fields

- **Username**
- **Password**
- **Config server** (M3 URL)

## Validation and Error States

- Failed connection checks show an inline error.
- Invalid credentials show an inline error and allow retry.
- Cancel closes startup flow.
