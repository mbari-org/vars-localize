# Search Panel

The search panel is the command center for loading imaged moments.

## Controls

- Search mode selector.
- Concept/UUID input field.
- **Go**, **Reset**, and **Open Video** actions.
- Result summary and loading indicator.

## Search Modes

- **Concept**: autocomplete and concept-based retrieval.
- **Imaged Moment UUID**: direct load by one or more UUIDs.
- **Image Reference UUID**: resolve image refs to moments.
- **Video Reference UUID**: resolve video refs to timeline-sorted moments.

## Results and Pagination

- Entry browser updates from query results.
- Pagination controls move through result pages.
- Loading disables conflicting controls.
