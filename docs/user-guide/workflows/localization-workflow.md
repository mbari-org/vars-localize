# Localization Workflow

This page documents the full operator flow from search to verified localization.

## Standard Flow

1. Login.
2. Search and load imaged moments.
3. Select moment and target observation.
4. Draw box.
5. Verify placement and dimensions.
6. Edit metadata in properties dialog if needed.

## Quality Checklist

- Box tightly encloses target.
- Observation concept matches target object.
- Part field is correct.
- No accidental duplicate boxes.

## Multi-Observation Sessions

For repeated annotations in one moment:

- Use concept focus controls to reduce visual noise.
- Clear observation selection between targets.
- Save and verify each box before moving to next row.
